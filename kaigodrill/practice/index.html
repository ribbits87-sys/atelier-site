介護特定技能評価試験の練習問題と試験の情報

特定技能（介護）の評価試験には、介護技能評価試験（45問・60分）と介護日本語評価試験（15問・30分）があります。「過去問」を探している方へ：厚生労働省のページに載っているのは、両方の試験のサンプル問題です（下の「試験について」からリンクしています）。

このページでは、カイゴドリルの問題から見本を載せました。どの問題にも、厚生労働省などが公開している資料の出典が付いています。

介護技能評価試験の形の問題

介護技能評価試験は、試験を行う国の言語で出題されます。

  1. 問1身体拘束(しんたいこうそく)が 例外的(れいがいてき)に 認(みと)められるのは、どんな ときですか。

    1. 家族(かぞく)から 強(つよ)く 希望(きぼう)された とき
    2. 夜間(やかん)に 職員(しょくいん)が 少(すく)なく 見守(みまも)れない とき
    3. 三(みっ)つの 要件(ようけん)を すべて 満(み)たす とき
    4. 利用者(りようしゃ)が 何度(なんど)も 立(た)ち上(あ)がる とき
    答えと解説

    正解：3　三(みっ)つの 要件(ようけん)を すべて 満(み)たす とき

    三(みっ)つの 要件(ようけん)は、切迫性(せっぱくせい)・非代替性(ひだいたいせい)・一時性(いちじせい)です。すべて 満(み)たす ときだけ、例外的(れいがいてき)に 認(みと)められます。一人(ひとり)で 決(き)めないで、施設(しせつ)の 判断(はんだん)として 複数(ふくすう)の 職員(しょくいん)で 確認(かくにん)します。

    出典：身体拘束ゼロの実践に向けて 介護施設・事業所における取組手引き（全日本病院協会（厚生労働省 老人保健健康増進等事業））（２）「緊急やむを得ない場合」の３要件

  2. 問2高齢者(こうれいしゃ)の 誤嚥(ごえん)に ついて、正(ただ)しい ものは どれですか。

    1. むせて いなければ 誤嚥(ごえん)は 起(お)きて いない
    2. 睡眠中(すいみんちゅう)に 唾液(だえき)が 肺(はい)に 入(はい)る ことが ある
    3. 高齢者(こうれいしゃ)の 咳(せき)の 反射(はんしゃ)は 若(わか)い 人(ひと)と 同(おな)じだ
    4. 口(くち)の 中(なか)を 清潔(せいけつ)に すれば 誤嚥(ごえん)は 起(お)きない
    答えと解説

    正解：2　睡眠中(すいみんちゅう)に 唾液(だえき)が 肺(はい)に 入(はい)る ことが ある

    高齢者(こうれいしゃ)は 咳(せき)の 力(ちから)が 弱(よわ)く なり、むせずに 誤嚥(ごえん)する「不顕性誤嚥(ふけんせいごえん)」が 起(お)こる ことが あります。

    出典：介護現場における感染対策の手引き 第2版（厚生労働省 老健局）８．誤嚥性肺炎（１）特徴

  3. 問3利用者(りようしゃ)に 咳(せき)や 痰(たん)、熱(ねつ)が ある とき、介護職員(かいごしょくいん)は どう しますか。

    1. 数日(すうじつ) 様子(ようす)を 見(み)てから 報告(ほうこく)する
    2. 風邪(かぜ)だと 思(おも)って 自分(じぶん)で 看病(かんびょう)する
    3. 家族(かぞく)が 来(き)た ときに 伝(つた)える
    4. 早(はや)めに 報告(ほうこく)して 受診(じゅしん)に つなげる
    答えと解説

    正解：4　早(はや)めに 報告(ほうこく)して 受診(じゅしん)に つなげる

    咳(せき)や 痰(たん)、熱(ねつ)などの 症状(しょうじょう)に 気(き)づいたら、早(はや)めに 報告(ほうこく)し、医師(いし)の 診察(しんさつ)を 受(う)けられるように します。

    出典：介護現場における感染対策の手引き 第2版（厚生労働省 老健局）８．誤嚥性肺炎（２）日頃の対応（予防法）

  4. 問4食事(しょくじ)の ときの 姿勢(しせい)で、正(ただ)しい ものは どれですか。

    1. 顎(あご)を 上(あ)げて 食(た)べ物(もの)を 流(なが)し込(こ)む
    2. 浅(あさ)く 腰(こし)かけて 後(うし)ろに もたれる
    3. 顎(あご)を 手前(てまえ)に 引(ひ)いた まま 食(た)べる
    4. ベッドを 平(たい)らに した まま 食(た)べる
    答えと解説

    正解：3　顎(あご)を 手前(てまえ)に 引(ひ)いた まま 食(た)べる

    顎(あご)を 手前(てまえ)に 引(ひ)いた 姿勢(しせい)に します。頭(あたま)が 後(うし)ろに 反(そ)ると 誤嚥(ごえん)しやすく なります。食事(しょくじ)の 前(まえ)には 利用者(りようしゃ)の 手(て)を 洗(あら)います。

    出典：介護現場における感染対策の手引き 第2版（厚生労働省 老健局）図25 各ケアのポイント

介護日本語評価試験の形の問題

介護日本語評価試験は、介護のことば（同じ意味のことばを選ぶ）、介護の会話・声かけ（会話を読んで合うものを選ぶ）、介護の文書（短い文書を読んで合うものを選ぶ）の3つの分野から、5問ずつ出ます。サンプル問題は文字だけで、すべての漢字にふりがなが付いています。

  1. きょうは 山田(やまだ)さんの「清拭(せいしき)」を します。

    問5「 」の ことばと 同(おな)じ 意味(いみ)を 選(えら)んで ください。

    1. お風呂(ふろ)で からだを 洗(あら)う
    2. シャンプーで 髪(かみ)を 洗(あら)う
    3. タオルで からだを ふく
    4. 歯(は)ブラシで 歯(は)を みがく
    答えと解説

    正解：3　タオルで からだを ふく

    「清拭(せいしき)」は、濡(ぬ)れた タオルなどで からだを 拭(ふ)いて、きれいに する ことです。入浴(にゅうよく)が できない ときなどに します。「清拭(せいしき)」の「拭(しき)」は「拭(ふ)く」と 同(おな)じ 漢字(かんじ)です。お風呂(ふろ)に 入(はい)る ことは「入浴(にゅうよく)」、髪(かみ)を 洗(あら)う ことは「洗髪(せんぱつ)」、歯(は)を みがく ことは「歯磨(はみが)き」と 言(い)います。

    出典：介護の特定技能評価試験 学習テキスト～介護技能・介護の日本語～ 改訂2版（公益社団法人 日本介護福祉士会（厚生労働省 介護の日本語学習支援等事業））p.230 入浴・清潔保持の介護 ことば（清拭⑧・洗髪⑨・入浴⑬・拭く⑮）・p.231 入浴できない場面で拭く・p.224 歯磨き⑲

  2. 介護職(かいごしょく)：田中(たなか)さん、もうすぐ 昼(ひる)ご飯(はん)です。食堂(しょくどう)へ 行(い)きましょう。

    田中(たなか)さん：きょうは 車(くるま)いすでは なくて、歩(ある)いて 行(い)きたいです。

    介護職(かいごしょく)：いいですね。膝(ひざ)の 痛(いた)みは どうですか。

    田中(たなか)さん：まだ 少(すこ)し 痛(いた)いです。

    介護職(かいごしょく)：では、歩行器(ほこうき)を 使(つか)いましょう。私(わたし)が そばに いますから、ゆっくり 歩(ある)きましょう。

    田中(たなか)さん：はい、そう します。

    問6会話(かいわ)の 内容(ないよう)で、正(ただ)しい ものを 選(えら)んで ください。

    1. 田中(たなか)さんは、歩行器(ほこうき)を 使(つか)って 食堂(しょくどう)へ 行(い)きます。
    2. 田中(たなか)さんは、車(くるま)いすに 乗(の)って 食堂(しょくどう)へ 行(い)きます。
    3. 田中(たなか)さんは、杖(つえ)を 使(つか)って 食堂(しょくどう)へ 行(い)きます。
    4. 田中(たなか)さんは、膝(ひざ)が 痛(いた)いので 部屋(へや)で 休(やす)みます。
    答えと解説

    正解：1　田中(たなか)さんは、歩行器(ほこうき)を 使(つか)って 食堂(しょくどう)へ 行(い)きます。

    田中(たなか)さんは 膝(ひざ)が まだ 少(すこ)し 痛(いた)いですが、歩(ある)いて 行(い)きたいと 言(い)いました。介護職(かいごしょく)が「歩行器(ほこうき)を 使(つか)いましょう」と 言(い)って、田中(たなか)さんは「そう します」と 答(こた)えました。「歩行器(ほこうき)」は、歩(ある)く ときに からだを 支(ささ)える 道具(どうぐ)です。

    出典：介護の特定技能評価試験 学習テキスト～介護技能・介護の日本語～ 改訂2版（公益社団法人 日本介護福祉士会（厚生労働省 介護の日本語学習支援等事業））p.208 移動の介護 ことば（車いす⑦・杖⑬・歩行器㉑）・p.205 膝㉙

  3. お知(し)らせ

    ご家族(かぞく)の みなさまへ

    5月(がつ)から、面会(めんかい)の 時間(じかん)を 変更(へんこう)します。

    今(いま)まで：午後(ごご)1時(じ)から 午後(ごご)6時(じ)まで

    5月(がつ)から：午後(ごご)1時(じ)から 午後(ごご)4時(じ)まで

    面会(めんかい)の 前(まえ)に、受付(うけつけ)で お名前(なまえ)を 書(か)いて ください。

    問7お知(し)らせの 内容(ないよう)で、正(ただ)しい ものを 選(えら)んで ください。

    1. 5月(がつ)から、面会(めんかい)は 午後(ごご)6時(じ)までです。
    2. 5月(がつ)から、面会(めんかい)は 午後(ごご)4時(じ)までです。
    3. 5月(がつ)から、面会(めんかい)の 時間(じかん)が 長(なが)く なります。
    4. 面会(めんかい)の 後(あと)に、受付(うけつけ)で 名前(なまえ)を 書(か)きます。
    答えと解説

    正解：2　5月(がつ)から、面会(めんかい)は 午後(ごご)4時(じ)までです。

    5月(がつ)から、面会(めんかい)の 時間(じかん)は 午後(ごご)1時(じ)から 4時(じ)までに 変(か)わります。今(いま)までより 2時間(じかん) 短(みじか)く なります。名前(なまえ)は 面会(めんかい)の 前(まえ)に 書(か)きます。「変更(へんこう)」は 変(か)える こと、「面会(めんかい)」は 家族(かぞく)などが 利用者(りようしゃ)に 会(あ)いに 来(く)る ことです。

    出典：介護の特定技能評価試験 学習テキスト～介護技能・介護の日本語～ 改訂2版（公益社団法人 日本介護福祉士会（厚生労働省 介護の日本語学習支援等事業））p.245 掲示⑤・p.246 面会・変更・p.258〜259 掲示の書き出し（〜の みなさまへ）

問題・答え・解説は、アプリの問題をそのまま載せています。アプリでは、選択肢の並びが毎回入れ替わります。

全問題と模擬試験はアプリで

カイゴドリルには、介護技能評価試験の学科4分野の問題240問、絵を見て判断する実技の練習27問、本番と同じ形の模擬試験（45問・60分）、介護のことば297語があります。

介護日本語評価試験の形の問題（3分野・150問）と、日本語の模擬試験（15問・30分）も、アプリで練習できます。

ダウンロードにも利用にも、料金はかかりません。広告で運営しています。

App Store（iPhone）Android版は準備中です
