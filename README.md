# atelier-site

Haven Atelier の Web サイト（https://atelier.thehaven.jp/）。GitHub Pages で公開しています。

**このリポジトリのファイルは、手で編集しないでください。** サイトはローカルの HavenAtelierHP フォルダ
（非公開）から自動で作り、`scripts/publish.mjs` でここへ写しています。ここを直接直すと、次の公開で
上書きされないよう公開が止まり、元のフォルダへの取り込みが必要になります。

- `app-ads.txt`、`CNAME`、`google…html` は、ストア・AdMob・Search Console に登録済みのため、場所を変えません
