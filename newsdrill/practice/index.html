時事問題の練習問題と、公務員試験の時事

ニュースドリルは、時事問題・一般常識の問題を解いて、公務員試験の時事に向けた基礎力を付けるクイズアプリです。配信した号の問題から、見本を載せました。

問題は日付を入れて書いていて、その時点で公表されている事実を問います。どの問題にも、官公庁や出来事の当事者が公表した資料の出典が付いています。

応用：「最も妥当なのはどれか」の形

応用（★3）の問題には、公務員試験の問題と同じ「〜に関する記述として、最も妥当なのはどれか」の形があります。

  1. 経済・応用｜第4号（2026年11月3日）

    問12026年10月30日の日本銀行の金融政策決定会合に関する記述として、最も妥当なのはどれか。

    1. 保有するETFの年間の売却ペースを、簿価(ぼか)で8,600億円程度に引き上げることを決めた。
    2. 保有するETFの年間の売却ペースを、簿価(ぼか)で3,300億円程度に引き下げることを決めた。
    3. 保有するETFの売却を、2027年1月から新たに始めることを決めた。
    4. 金融市場調節方針を、9人の政策委員の全員一致で決めた。
    答えと解説

    正解：1　保有するETFの年間の売却ペースを、簿価(ぼか)で8,600億円程度に引き上げることを決めた。

    日本銀行は、ETFの売却について、市場全体の売買代金に占める売却割合が0.1%程度となる規模とし、年間の売却ペースを簿価で3,300億円程度から8,600億円程度に引き上げることを全員一致で決めた。新しいペースは2027年1月から実施する。ETFの売却そのものは2026年1月に始めている。金融市場調節方針は賛成8・反対1で決まった（1人の委員が1.5%程度への引き上げを提案し、反対多数で否決された）。

    出典：日本銀行「当面の金融政策運営について」／日本銀行「（参考）ETFの売却ペースの見直しに関する決定（2026年10月）」

  2. 政治・応用｜第6号（2026年11月10日）

    問2会計検査院に関する2026年11月時点の記述として、最も妥当なのはどれか。

    1. 会計検査院は、内閣府に置かれ、内閣総理大臣の指揮を受けて検査を行う。
    2. 会計検査院は、国会や裁判所に属さず、内閣に対して独立の地位を持つ。
    3. 会計検査院が検査するのは国の収入支出の決算で、国が補助金を出している地方公共団体の会計は検査の対象にならない。
    4. 国の収入支出の決算は、会計検査院が2年に1度、まとめて検査する。
    答えと解説

    正解：2　会計検査院は、国会や裁判所に属さず、内閣に対して独立の地位を持つ。

    会計検査院は、国会や裁判所に属さず、内閣に対して独立の地位を持つ憲法上の機関。日本国憲法第90条は、国の収入支出の決算を、すべて毎年、会計検査院が検査すると定める。国が出資している法人や、国が補助金などを出している地方公共団体の会計も検査している。

    出典：会計検査院「会計検査院とは（2026年11月9日に確認）」

  3. 国際・応用｜第5号（2026年11月6日）

    問3APEC（アジア太平洋経済協力）に関する2026年11月時点の記述として、最も妥当なのはどれか。

    1. APECに参加している国・地域（エコノミー）の数は、27である。
    2. APECには、ロシアは参加しておらず、アジアの国・地域だけが参加している。
    3. 2025年のAPECの議長は、日本だった。
    4. 香港は「ホンコン・チャイナ」、台湾は「チャイニーズ・タイペイ」の名称で参加している。
    答えと解説

    正解：4　香港は「ホンコン・チャイナ」、台湾は「チャイニーズ・タイペイ」の名称で参加している。

    外務省によると、APECの参加国・地域は21のエコノミーで、ロシアのほか、米国・カナダ・メキシコ・チリ・ペルーなども参加している。香港は「ホンコン・チャイナ」、台湾は「チャイニーズ・タイペイ」の名称で参加している。2025年の議長は韓国だった。

    出典：外務省「茂木外務大臣のAPEC閣僚会議への出席（概要）」

標準・基本の問題

  1. 経済・標準｜第4号（2026年11月3日）

    問42026年11月時点で、厚生労働省が毎月公表している有効求人倍率は、何を何で割った数か。

    1. 月間有効求人数を、月間有効求職者数で割った数
    2. 月間有効求職者数を、月間有効求人数で割った数
    3. 就職件数を、月間有効求職者数で割った数
    4. 月間有効求人数を、就業者数で割った数
    答えと解説

    正解：1　月間有効求人数を、月間有効求職者数で割った数

    厚生労働省の一般職業紹介状況では、有効求人倍率は、ハローワークでの月間有効求人数を、月間有効求職者数で割って出している。1倍を上回るのは、月間有効求人数が月間有効求職者数より多いとき。2026年9月は1.19倍（季節調整値）だった。

    出典：厚生労働省「一般職業紹介状況（令和8年9月分）について」／厚生労働省「一般職業紹介状況（令和8年9月分）について（報道発表資料）」

  2. 政治・標準｜第1号（2026年10月23日）

    問5首相官邸の説明で、閣議は誰による会議とされているか。

    1. 内閣総理大臣と国務大臣
    2. 内閣総理大臣と事務次官
    3. 衆参両院の議長と国務大臣
    4. 衆参両院の議長と事務次官
    答えと解説

    正解：1　内閣総理大臣と国務大臣

    首相官邸は、閣議を「内閣総理大臣と国務大臣（閣僚）による会議」と説明している。閣議には、内閣官房副長官と内閣法制局長官が陪席(ばいせき)する。2026年10月20日には、この閣議で「AI・デジタル改革推進会議」を開くことが決まった。

    出典：首相官邸「閣議（2026年10月23日に確認）」／首相官邸「内閣制度の概要（2.2 内閣の機能と運営。2026年10月23日に確認）」／首相官邸「令和8年10月20日（火）定例閣議案件」

  3. 科学・技術・標準｜第2号（2026年10月27日）

    問6個々の大雨などの極端な気象に、長い期間の地球温暖化がどのくらい影響したかを、科学的に数値で示す手法を何というか。

    1. アンサンブル予報
    2. ナウキャスト
    3. イベント・アトリビューション
    4. ハザードマップ
    答えと解説

    正解：3　イベント・アトリビューション

    文部科学省の発表資料は、この手法をイベント・アトリビューションと呼んでいる。この発表では、実際の大雨を再現した計算と、温暖化の分を除いた計算を比べて評価した。

    出典：文部科学省「令和8年8月から9月に各地で発生した記録的大雨に地球温暖化が影響 －イベント・アトリビューションによる結果－（発表資料）」

  4. 社会・暮らし・標準｜第5号（2026年11月6日）

    問72026年11月時点で、春秋の叙勲は毎年2回行われ、春の叙勲は5月3日付けで授与される。

    ○か×で答える問題です。

    答えと解説

    正解：×

    内閣府によると、春秋叙勲は毎年2回で、春は4月29日付け、秋は11月3日付けで授与される。2026年の秋の叙勲も、11月3日付けで発令された。

    出典：内閣府「勲章・褒章制度の概要（2026年11月5日に確認）」／内閣府「令和8年秋の叙勲等の受章者数及び受章者名簿（令和8年11月3日付け発令）」

問題・答え・解説・出典は、配信した号の問題をそのまま載せています（アプリでは、選択肢の順が毎回入れ替わります）。

ほかの問題はアプリで

火曜と金曜の朝6時半（日本時間）に、その期間の出来事から作った新しい号が届きます。答えると、解説と、問題のもとになったニュース（短い記事と出典）を読めます。

公務員試験の時事（国家公務員 一般職・大卒程度）

基礎能力試験
第1次試験。30題・多肢選択式・1時間50分人事院「2026年度 国家公務員採用一般職試験（大卒程度試験）受験案内」
時事の出題
30題のうち、知識分野の6題が「自然・人文・社会に関する時事、情報」。残りの24題は知能分野（文章理解10・判断推理7・数的推理4・資料解釈3）。「行政」区分の例人事院「2026年度 国家公務員採用一般職試験（大卒程度試験）受験案内」
2024年度からの変更
春の大卒程度試験の基礎能力試験は、40題から30題になった。知識分野は時事問題を中心にし、ふだんから社会の動きに関心を持っていれば答えられる内容にする、と人事院は説明している人事院「2024年度の国家公務員採用試験における主な変更点について」
見直しの前と後
知識分野は、見直しの前が13題「自然・人文・社会（時事を含む）」、見直しのあとが6題「自然・人文・社会に関する時事、情報」人事院「基礎能力試験の見直し」
試験問題例
人事院が、時事の試験問題例を公開している人事院「試験問題例」
地方公務員の試験
都道府県・市町村などの試験の中身は、自治体ごとに違う。受ける自治体の受験案内で確かめてください

2026年11月13日に、各行のリンク先のページで確かめた内容です。日程と申込みは、リンク先で最新の案内をご覧ください。
