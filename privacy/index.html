01このサイトで扱う情報

このサイトには、会員登録やお問い合わせのフォームはありません。アクセス解析（Google アナリティクスなど）や広告も使っていません。

このサイトは、GitHub, Inc. の GitHub Pages で公開しています。ページを表示するとき、通常のウェブサイトと同じように、GitHub のサーバーにアクセスの記録（IP アドレス、日時、ブラウザの種類など）が残ることがあります。運営者はこの記録を受け取っておらず、利用者を特定するためには使いません。

文字の表示に Google Fonts を使っています。ページを開くと、お使いのブラウザが Google のサーバーから文字のデータを読み込み、そのとき IP アドレスなどが Google に送られます。くわしくは Google のプライバシーポリシー をご覧ください。

ふりがなの表示・非表示の設定は、お使いのブラウザの中にだけ保存され、どこにも送られません。

02お問い合わせで受け取る情報

メールでお問い合わせいただいた場合、メールアドレス、お名前（書かれている場合）、お問い合わせの内容を受け取ります。

受け取った情報は、お問い合わせへの返信と、その内容への対応（アプリの不具合や問題の誤りの確認と修正など）のためだけに使います。

お問い合わせのメールは、メールの転送サービス（ImprovMX）を通じて Google の Gmail で受け取り、運営者だけが使うアカウントで管理しています。

03安全管理のための措置

お問い合わせのメールを読み、扱うのは運営者だけです。

メールのアカウントには2段階認証を設定し、運営者のほかには使えないようにしています。

メールの転送には米国の ImprovMX Incorporated の、受信と保管には米国の Google LLC の Gmail を使っています。米国の個人情報の保護の制度を確かめたうえで、これらの措置をとっています。

04第三者への提供

お預かりした個人情報は、法令にもとづく場合を除き、ご本人の同意なく第三者に提供しません。

05開示・訂正・削除のご依頼

ご自身の情報の開示・訂正・利用の停止・削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。ご本人であることを確かめたうえで、遅滞なく対応します。

06外部のサイト

このサイトから App Store、Facebook、e-Gov 法令検索、省庁のサイトなどの外部のサイトへ移ったあとの情報の扱いは、それぞれのサイトの方針によります。
